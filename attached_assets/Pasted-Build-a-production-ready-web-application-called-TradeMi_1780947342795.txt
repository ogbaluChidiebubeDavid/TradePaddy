Build a production-ready web application called TradeMind AI.

TradeMind AI is an AI Trading Operating System designed specifically for the Bitget AI Base Camp Hackathon Trading Agent track.

The platform combines:

* Autonomous Trading Intelligence
* Portfolio Analysis
* Trade Execution (Simulation)
* Long-Term Memory
* Behavioral Analytics
* Personalized Coaching
* Trade Replay

The system should not only help users discover and execute trades but also explain historical performance and improve trader behavior over time.

Perception → Decision → Execution → Risk Management
